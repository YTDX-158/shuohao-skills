# Seedance 视频提示词 · 每镜写法规范（内化版）

方法论学自实战样本（真人电影风格 / 写实向半厚涂）+ seedance-20-ytdx 摄影参考，内化成本 skill 自带文档——不依赖任何外部 skill。写每个镜的 `seedancePrompt` 照这份做，结构部分有质量门逐字对账。

## 结构（模型手写，validate 逐字对账的部分）

```text
<风格声明>，画面不要出现任何文字，生成视频无BGM；

c<镜号>,<seconds>s,(空间:<space>)(姿态:<pose>)(位置:<position>)(情绪:<mood>)
<shotDesc>
@说话人用中文[语气]地说道<台词>
【不出现任何文字字幕】
```

五段：① 头部风格声明（全片统一，含无文字/无BGM）② 镜号行（固定时长 + 元数据四件套）③ 视觉描述 ④ 台词 ⑤ 无字幕强调。

## 结构化元数据（四件套）

- **空间**：本镜环境（如「昏暗狭小房间远端」「养老院院子中央树荫下」）
- **姿态**：全画内角色，`@老张-坐在藤椅上摇@蒲扇; @老人甲-坐着`（分号分隔）
- **位置**：全画内角色，`@老张-藤椅左侧、面朝@老人甲; ...`（**含"面朝@谁"视线关系**，正反打地基）
- **情绪**：只写本镜主角，`@老张-悠闲 2/10`（程度值驱动语速/表演）

**@绑定 = 图片绑定**：`@老张` / `@蒲扇` → 上传的设定图（角色/道具）。每个 `@X` 必须在资产库存在（质量门查）。

## 视觉描述

- **每镜一个主运镜**（Static / Push In / Pull Out / Tracking…），固定镜头是默认，推给情绪、拉给收场、跟给移动，一段里超过两种运镜是在炫技
- **光影设计**：色温 → 色调表达（暖 amber / 冷 blue-grey / 低照度 / 高反差），器材数字（ISO/快门）不写进提示词
- **微动作**：写模型见过的简单动作（摇扇/轻叩桌面/挑眉/撇嘴），精确物理交互、微表情不要写
- **时间维度**：给画面"活"感（尘埃旋转、呼吸起伏、布料飘动）
- **禁慢速词**：不用「缓缓/静静」，情绪译成身体动作（眉头紧锁/咬牙切齿），短剧要快、冲、有张力
- **5 秒时间轴**（一镜内动作分配）：0-1s 起势 → 1-2s 爆发 → 2-3s 交互 → 3-4s 高潮 → 4-5s 余韵，**禁止静止**

## 台词

- `@说话人用中文[语气]地说道<台词>`：说话人 + 语言 + 语气 + 台词
- 台词**按剧本原始语言逐字**，一个标点都不许动（门盯着）
- 画外音：注明「以画外音说（唇形完全闭合）」
- 声景是动作指令：画面动作一改，描述一起改

## 定时长（四步法）

1. **台词定下限**：字数 ÷ 5.5（中文短剧语速）＋情绪系数联动（紧张 ×1.1 / 温情 ×0.9）
2. **类型定基准**：反应镜 1-2s / 纯动作 2.5s / 基础 3s / 信息量大 4-6s
3. **长台词优先拆镜**：拆不动给到 6s（上限）
4. **节奏相间**：长短深浅不匀，重台词后接短反应（5s 接 1s）

校验链：台词秒数 ≤ 镜秒数 ≤ 6s · 段 Σ镜 ≤ 15s · 集 Σ段 = 剧本目标 ±15%

## 摄影参考（内化自 seedance-20-ytdx）

### 景别 ↔ 焦段匹配
| 景别 | 焦段 | 表现力 |
|------|------|--------|
| 大远景/远景 | ≤24mm 广角 | 宏大环境、人环关系 |
| 全景 | 24-35mm | 全身 + 环境 |
| 中景 | 35-50mm | 腰部以上，兼顾动作与背景 |
| 中近景 | 50-85mm | 胸部以上，聚焦表情 |
| 特写 | 85-135mm+ | 压缩空间、虚化背景、突出细节 |
| 大特写 | 100mm+ | 极致细节 |

焦段词只在有助于导演时写（`85mm shallow close-up`），别堆数字当装饰。

### 运镜 × 焦段联动
- 广角 + 运动 → 空间感强、速度感明显 → 环境揭示/进场
- 长焦 + 运动 → 空间压缩、主体缓慢移动 → 跟踪特写
- 标准 + 运动 → 最接近人眼 → 对话/日常动作

### 色温 → 色调
| 真实参数 | 情绪 | 提示词写法 |
|---------|------|-----------|
| 3200K 暖调 | 温馨怀旧 | `warm amber tones, golden glow` |
| 5600K 冷调 | 冷峻疏离 | `cold blue-grey palette` |
| 低照度 | 压抑悬疑 | `dim low-key lighting, deep shadows` |
| 高反差 | 紧张戏剧 | `hard contrast, stark shadows` |

### 统摄哲学
写任何镜前先答：**这段戏要让观众感到什么？**
感到紧张 → 手持轻微晃动 + 低照度 + 快速运动；感到亲近 → 中近景 50-85mm + 慢推 + 暖调；感到宏大 → 大远景 ≤24mm + crane 上升 + 冷调。
所有技术参数是同一个叙事意图的不同侧面——选完互相印证，不各自为政。
