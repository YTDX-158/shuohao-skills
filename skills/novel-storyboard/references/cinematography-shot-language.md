# 镜头语言 · 每镜的具体拍法（内化自 seedance-20-ytdx cinematography-shot-language）

`references/directing-read.md` 判断这段戏要干什么，`references/directing-engine.md` 决定每个镜怎么为意图服务，这份给出**镜头手段本身怎么说**——景别/机位/运镜/起点终点/脆弱锚点。写每镜的 `shotDesc` 时照这份做。

## 镜头契约：每镜至少声明这些

| 字段 | 决定 |
|---|---|
| **景别** | extreme wide 大远景 / wide 远景 / medium 中景 / close 近景 / extreme close 特写 |
| **机位角度** | 平视 / 低机位 / 高机位 / 俯拍 / 侧拍 / 过肩 / 特写插入 |
| **焦段感** | 广角空间感 / 35mm 自然 / 长焦压缩 / 微距材质细节 |
| **运镜** | 固定 / 手持 / 推近 / 拉远 / 横移 / 环绕 / 升降 / 摇移 / 对焦转移 |
| **起点画面** | 镜头开始的第一个可读构图 |
| **落点画面** | 结束时变化了的状态/姿态/揭示/手递 |
| **脆弱锚点** | 脸 / 手 / 道具位置——运镜必须护住它们 |

**焦段数值**：上面的"焦段感"是感受方向，具体焦段↔景别匹配表（大远景 ≤24mm、中景 35-50mm、特写 85mm+ 等）在 `references/seedance-prompt.md` 的摄影参考节。

**一段标准拍法**：`[景别/机位/焦段]。镜头从[起点构图]起，[一个运镜]在[速度]，同时[主体动作]，落在[清晰落点]。护住[脆弱锚点]。`

## 景别用法（按戏的类型选）

| 景别 | 用在哪 | Seedance 注意 |
|---|---|---|
| **大远景** | 尺度、到达、环境 | 人脸/文字会漂，别要求面部表演 |
| **远景** | 调度、舞蹈、运动、产品与环境 | 动作保持简单可读 |
| **中景** | 对白、产品使用、手递 | 角色广告的好默认 |
| **近景** | 情绪、材质、口型、产品细节 | 机位稳住、动作放小 |
| **特写** | 材质、食物、珠宝、机械 | 避免大动作和文字重绘 |

**对治"中景黏糊"的关键**：对白戏不等于全中景。亲密对话用近景怼脸；反应镜用特写；关系变化用过肩或侧拍。景别该跟着"这段戏的情绪浓度"走，不是统一中景。

## 运镜语法（每种为什么用）

| 运镜 | 用在哪 | 别用在哪 |
|---|---|---|
| **固定** | 对口型、身份展示、文字、精确VFX、连贯锚点 | —— |
| **推近** | 发现、醒悟、亲密、产品揭示 | —— |
| **横移** | 行进、队列、编舞、前景层次掠过 | —— |
| **环绕** | 产品英雄、雕塑式主体 | 需要单一角度锁身份时避免 |
| **升降/航拍** | 尺度、到达、地理、揭示 | 对白或小产品文字 |
| **手持** | 写实或紧张感 | 需要保身份时别晃动 |
| **对焦转移** | 两个锚定物之间的注意力切换 | 别叠复杂的运镜 |

**对治"全 Static"的关键**：不是每镜都运动，但**该推的时候推、该摇的时候摇**。灾难戏（罗刹鬼崩楼）该有推近/升降/横移，揭示戏（童童现身）该有推近，权力戏（红色纸人进教室）该有低机位仰拍——固定机位留给口型、身份、连贯锚点。运镜要有理由，不为动而动。

## 连贯机位（一场多镜时）

1. 先确立地理和屏幕方向
2. 再移到人物/道具动作
3. 细节特写只在这个细节改变剧情时用
4. 每镜落点都能成为下一镜的起点参考

覆盖模式：`镜1 大远景确立[空间/方向]。镜2 中景跟[动作]。镜3 近景揭示[后果]。连贯：同一套服饰、道具、光方向、视线。`

## 禁用词（写了就是 AI 味）

❌ `cinematic camera`、`dynamic shot`、`epic zoom`、`film look`、`Hollywood style`、`beautiful composition`

✅ 换成：具体的景别 + 机位 + 运镜 + 主体关系 + 有来源的光 + 落点 + 脆弱锚点。
