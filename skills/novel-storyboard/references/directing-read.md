# 导演读解 · 每段切镜前的戏判断（内化自 seedance-20-ytdx directors-read）

写分镜前，先做一遍这个读解。**目的是让每个镜"拍什么、为什么这么拍"有依据**——不是从格式出发，是从"这段戏要观众感受到什么"出发。

> 这份是判断流程，不是输出格式。读解结果**不写进 seedancePrompt**，只用来指导怎么切镜、怎么选镜头、怎么让台词跟画面对上。最终提示词里只出现"可见的东西"（动作、机位、光线），不出现"内心感受"这种词。

## 第一步：先分类——这段戏是"叙事"还是"纯画面"

**叙事戏**（绝大多数）——有人物在追求/抵抗/选择/隐瞒/反应/关系变化，或有一段剧情转折。比如：林风期待唤醒童童、胖子被红色纸人指点融合、楚楚撩人被拆穿。

**纯画面**（少数）——纯环境/灾难/转场/蒙太奇，没有人物戏剧。比如：开场的城市灾难蒙太奇、罗刹鬼崩楼、骷髅山。这种不做十字段记录，只写"这段镜头要传达什么氛围"。

## 第二步：叙事戏——做十字段记录（对着这一段戏想清楚）

**不是每个镜都做，是每"段"（情绪弧线单元）做一次**，然后段内每镜都服从这个判断。

1. **戏剧功能**：这段戏在整集里干什么——引入 / 深化 / 转折 / 考验 / 揭示 / 决断 / 兑现
2. **转折**：这段戏让观众从什么感觉变成什么感觉（安全→威胁 / 希望→绝望 / 陌生→亲近 / 控制→失控 / 日常→惊奇）。没有转折的戏是装饰，该砍或合并
3. **视角**：观众的"身体"站在谁那边？这场戏我们跟着谁的经历走
4. **权力**：谁有权力、谁想要、权力在这段里怎么移动。权力用高低/大小/谁看谁/谁占空间表达
5. **潜台词**：什么是真的但没说出口？台词和真正想要的东西之间的缝，就是戏

## 第三步：把读解"翻译成可见的东西"

| 内部读解 | 变成画面/声音 |
|---|---|
| 视角 | 镜头位置、给不给观众信息、视线方向、声音角度 |
| 权力变化 | 高低机位、画面占比、距离、谁先动、谁让出空间 |
| 潜台词/矛盾 | 嘴上说的和身体做的不一致（笑着但攥紧杯子） |
| 隐藏的意图 | 一个任务、一个道具动作、一次靠近/后退/延迟 |
| 转折 | 一个看得出的"之前→之后"状态变化 + 镜头落点 |
| 不可转移的细节 | 那个只有这部剧才有的物件/动作/声音，必须保留 |

**关键规则：不许把"他感到背叛""气氛紧张"这种词写进提示词。** Seedance 渲染的是"看得见的行为"，不是内心感受。要把感受换成"一个身体真会做的动作"。

例：不说"林风很期待"，说"林风把蝴蝶结举到眼前，眼睛跟着它慢慢发亮"。不说"红色纸人很权威"，说"红色纸人抬起纸手，教室里的声音立刻停了"。

## 第四步：防最省事的拍法（stock solution）

每个类型都有最偷懒的默认拍法，要主动拒绝：

- 悲伤戏 → 拒绝"特写哭脸 + 煽情配乐"，换成具体的动作（把信压平、没抬头）
- 打斗戏 → 拒绝"慢动作 + 冲击蒙太奇"
- 惊奇戏 → 拒绝"飘浮粒子 + 镜头光晕"
- 灾难戏 → 拒绝"环绕运镜 + 无意义大场面"

## 一句话检查

写完整段分镜后自问：**每镜的画面是不是都在为一个"同一件事"服务？** 如果镜头 A 在演紧张、镜头 B 在演抒情、镜头 C 在演搞笑，这段戏就没有一个明确的意图——需要回第一步重新判断这段戏到底要干什么。
