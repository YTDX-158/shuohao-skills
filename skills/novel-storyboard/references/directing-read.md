# 导演读解 · 每段切镜前的戏判断（内化自 seedance-20-ytdx directors-read）

写分镜前，先做一遍这个读解。**目的是让每个镜"拍什么、为什么这么拍"有依据**——不是从格式出发，是从"这段戏要观众感受到什么"出发。

> 这份是判断流程，不是输出格式。读解结果**不写进 seedancePrompt**，只用来指导怎么切镜、怎么选镜头、怎么让台词跟画面对上。最终提示词里只出现"可见的东西"（动作、机位、光线），不出现"内心感受"这种词。

## 第一步：先分类——这段戏是"叙事"还是"纯画面"

**叙事戏**（绝大多数）——有人物在追求/抵抗/选择/隐瞒/反应/关系变化，或有一段剧情转折。比如：林风期待唤醒童童、胖子被红色纸人指点融合、楚楚撩人被拆穿。

**纯画面**（少数）——纯环境/灾难/转场/蒙太奇，没有人物戏剧。比如：开场的城市灾难蒙太奇、罗刹鬼崩楼、骷髅山。这种不做十字段记录，只写"这段镜头要传达什么氛围"。

## 第二步：叙事戏——做十字段记录（对着这一段戏想清楚）

**不是每个镜都做，是每"段"（情绪弧线单元）做一次**，然后段内每镜都服从这个判断。十个字段，能填的都填，填不出的是"这段戏还没想清楚"的信号：

1. **戏剧功能**：这段戏在整集里干什么——引入 / 深化 / 转折 / 考验 / 揭示 / 决断 / 兑现
2. **转折**：这段戏让观众从什么感觉变成什么感觉（安全→威胁 / 希望→绝望 / 陌生→亲近 / 控制→失控 / 日常→惊奇）。没有转折的戏是装饰，该砍或合并
3. **视角**：观众的"身体"站在谁那边？这场戏我们跟着谁的经历走
4. **权力变化**：谁有权力、谁想要、权力在这段里怎么移动。权力用高低/大小/谁看谁/谁占空间表达
5. **隐藏意图**：主体想得到/保护/避免/证明/隐瞒什么。没有人物主体的戏（纯事件）用这场戏的戏剧目标，别给物体编心理
6. **障碍与策略**：什么挡着目标，主体用什么看得见的动作应对它
7. **潜台词/矛盾**：表面上说的和底下真正想要的之间的缝——嘴上说没事、身体在往门口挪
8. **可见抑制行为**：一个能拍到的、小动作，展示一个冲动被压住/转向/泄漏（原文里对治"台词跟画面对不上"最有力的一条：握紧又松开、欲言又止、手伸出去又收回来）
9. **不可转移细节**：一个只有这部剧才有的物件/仪式/台词/地点事实/服装事实/声音/行为——别的剧拿不走的那种
10. **拒绝的偷懒拍法**：这个类型最省事的默认拍法，这场戏明确不用（见第四步）

## 第三步：把读解"翻译成可见的东西"

| 内部读解 | 变成画面/声音 |
|---|---|
| 视角 | 镜头位置、给不给观众信息、视线方向、声音角度 |
| 权力变化 | 高低机位、画面占比、距离、谁先动、谁让出空间 |
| 隐藏意图 | 一个任务、一个道具动作、一次靠近/后退/延迟 |
| 障碍/策略 | 看得见的阻碍 + 一个可拍的应对动作 |
| 潜台词/矛盾 | 嘴上说的和身体做的不一致（笑着但攥紧杯子） |
| 可见抑制行为 | 一个能被镜头停住读懂的、有时的动作 |
| 转折 | 一个看得出的"之前→之后"状态变化 + 镜头落点 |
| 不可转移细节 | 那个只有这部剧才有的物件/动作/声音，必须保留 |

**关键规则：不许把"他感到背叛""气氛紧张"这种词写进提示词。** Seedance 渲染的是"看得见的行为"，不是内心感受。要把感受换成"一个身体真会做的动作"。

例：不说"林风很期待"，说"林风把蝴蝶结举到眼前，眼睛跟着它慢慢发亮"。不说"红色纸人很权威"，说"红色纸人抬起纸手，教室里的声音立刻停了"。

## 第四步：防最省事的拍法（stock solution）

每个类型都有最偷懒的默认拍法，要主动拒绝——**拒绝要具体到"这一场"**，不说"别用俗套"，要说"不用特写哭脸+煽情配乐"：

- 悲伤戏 → 拒绝"特写哭脸 + 煽情配乐"，换成具体的动作（把信压平、没抬头）
- 打斗戏 → 拒绝"慢动作 + 冲击蒙太奇"
- 惊奇戏 → 拒绝"飘浮粒子 + 镜头光晕"
- 灾难戏 → 拒绝"环绕运镜 + 无意义大场面"

## 第五步：十字段长什么样（样例）

以"楚楚撩林风被拆穿"为例：

1. 戏剧功能：**深化**（展示林风的冷静和楚楚的虚荣）
2. 转折：**主动撩 → 被反将一军**（她以为占上风，实际被看穿）
3. 视角：楚楚——观众跟着她的尴尬走
4. 权力变化：**她先占主动权（弯腰俯视），被拆穿后权力倒向林风**（林风坐着不动但气场压制）
5. 隐藏意图：楚楚想撩林风/证明自己有魅力，不想被看穿
6. 障碍/策略：林风不接招；她先愣住，再嘴硬补一句"想跟老娘生孩子的多的是"
7. 潜台词/矛盾：嘴上说"切，想跟老娘…"，其实被拆穿有点下不来台
8. 可见抑制行为：**她弯腰的动作一滞（僵了半拍才站直）**——这个"滞"就是戏
9. 不可转移细节：波点蝴蝶结（这是这部剧的信物，别的剧拿不走）
10. 拒绝的偷懒拍法：不用"两人正反打近景来回切"的偷懒覆盖，用弯腰的高度差表现权力

## 一句话检查

写完整段分镜后自问：**每镜的画面是不是都在为一个"同一件事"服务？** 如果镜头 A 在演紧张、镜头 B 在演抒情、镜头 C 在演搞笑，这段戏就没有一个明确的意图——需要回第一步重新判断这段戏到底要干什么。
