# 导演引擎 · 场景怎么拍（内化自 seedance-20-ytdx directing-engine）

读完 `references/directing-read.md`（这段戏要干什么）之后，用这份决定"每个镜具体怎么拍"。

## 核心：一个意图，所有乐器弹同一个音

**先想出一个意图句**——"让观众感到林风的期待正在变成紧张"。然后每个镜头的选择（景别/机位/运镜/光线/表演/时长）都朝这个意图使劲。

当镜头、光、表演、剪辑都指向同一个感受，这段戏读起来就是"被导演过的"。当每个元素各自挺好看但方向不一样，就是"高级但空洞"。

| 乐器 | 承载什么 | 怎么表达意图 |
|---|---|---|
| 景别 | 距离 = 亲密或审判 | 越近越进入内心；越远越强调处境/孤立/宏大 |
| 机位高度 | 权力与同情 | 低机位仰拍 = 强化；高机位俯拍 = 削弱；平视 = 平等 |
| 焦段 | 心理空间 | 长焦压缩孤立；广角打开空间或产生压迫 |
| 运镜 | 观众的本能冲动 | 推近 = 逼近一个认知；拉远 = 放弃或揭示语境；静止 = 屏住一口气 |
| 光线 | 情绪暴露 | 主光方向/对比/色温决定安全还是威胁、温暖还是疏离 |
| 表演 | 这一刻的真相 | 一个看得见的身体动作演潜台词 |
| 时长 | 呼吸与压力 | 延长积累重量；切开释放或加速 |

## 场景类型 → 一套完整的拍法

不同戏份有不同的完整拍法，**每个类型是一整套配套的**，不是随便挑几个镜头拼：

| 戏的类型 | 导演问什么 | 完整拍法 |
|---|---|---|
| **亲密对白** | 我们进入谁的内心？ | 中近景到特写、平视、长焦、极少运镜（固定为主，**情绪浓度高的那一句给一个慢推 Push In**）、柔和主光、声音稀疏。表演靠微动作：一个停住的注视、一句咽下去的话、手出卖平静 |
| **对峙/权力** | 权力在谁那、往哪移？ | 对立的机位、高度编码地位、长焦隔离双方、光线冷暖分裂、遮挡拉近距离。静止=掌控，一点失态=转折 |
| **揭示/发现** | 观众什么时候学到什么？ | 先藏后露——画面先遮住，再靠运镜/光线变化揭开；镜头跟着主体一起发现。**反应比被发现的物体更重要** |
| **决断/转折** | 这个选择付出什么代价？ | 推近孤立做决定的人；世界安静下来；一个动作完成选择；光随决定变化 |
| **到达/确立场景** | 这是什么世界、主体在哪？ | 大远景到中远景、有动机的环境光、把主体放进空间的运镜、环境声 |
| **追逐/动作** | 运动里赌的是什么？ | 跟踪/手持能量、屏幕方向纪律、对比光、声音变厚；一个清晰的身体目标 |
| **变身/特效** | 什么变了、什么证明了它？ | 锁定或受控的机位让变化看得清；光跟着变化走；一个原因、看得见的后果 |
| **喜剧节拍** | 节奏点在哪？ | 锁定画面、干净地理、面无表情的停顿、一个荒诞的可见动作、一个干脆的声音。让画面停过不舒服的点 |
| **情绪低谷** | 他有多孤独？ | 距离和静止、冷而软的光、负空间、接近无声；镜头旁观，不推 |
| **产品英雄** | 什么让它显得好且真实？ | 从环境到细节的受控移动、材质上的动机光、锁定身份、干净声音 |

**对话戏别整段全固定**：固定机位是对话的默认（Seedance 对运镜敏感，固定拍对白最稳），但**情绪浓度高的那一句**——告白、揭穿、动情、威胁——该给一个慢推（Push In）或切近景，让镜头语言有呼吸。判断标准：这一句是不是这段戏的情绪顶点？是就给运镜，不是就保持固定。**整段对白 4-5 个镜全 Static，观众会闷。**

## 表演：把"情绪词"换成"看得见的动作"

**Seedance 渲染的是可见行为，不是内心状态。**"她很悲伤""他感到背叛""气氛紧张"——这些没有像素，不可拍。

| ❌ 情绪词 | ✅ 一个身体真会做的动作 |
|---|---|
| 林风很期待 | 林风把蝴蝶结举到眼前，眼睛跟着它慢慢发亮 |
| 胖子很害怕 | 胖子盯着渗血的断指，喉咙发紧，往后缩了半步 |
| 童童很冷漠 | 童童没看任何人，脚步踩在冰霜上，声音平平的 |
| 楚楚很得意 | 楚楚把芭比娃娃举到胸前，下巴微抬，斜眼瞟向林风 |

**一个短镜只给一个动作。** 几秒的镜里，一个具体、可读的动作比一长串情绪更有力。选那个"包含转折"的动作。

## 连贯性测试：每镜开拍前过六关

1. **意图一句话**——说不出来，说明读解没做完
2. **指向检查**——每个镜头元素都在表达意图吗？有反着来的就删或改
3. **行为检查**——表演是看得见的动作吗？不是情绪词吧
4. **动机检查**——光有来源吗（窗/灯/太阳）？运镜有理由吗（跟着动作）？
5. **声音检查**——这镜的风格跟整部剧一致吗？不一致是有意的转折吗？
6. **脆弱检查**——这个复杂度会不会毁脸/手/道具？会就简化运镜，让光或环境来承担变化

## 反AI味清单（导演层面）

拒绝：为炫技而炫技的镜头；把"电影感/史诗/好看"当目标；一部剧里混多种导演风格；把表演写成情绪词；没理由的运镜；没来源的光；每个元素单看不错但指向不同方向。

**修复方法永远是同一个**：回到那一句话的意图，让每个选择都为它服务。
