# 切镜：一集怎么分组、怎么切

一次任务切一集。你拿到 seedScenes 工作底稿（每场的节拍清单：编号、动作/台词、每拍秒数、说话人）、场景卡、角色卡。产出：把这一集的 `segments` 从空切满，然后删掉 `seedScenes`。

## 先分组，再切镜

1. **段 = 情绪弧线单元**，≤ 15 秒，不跨场次。先把每场的节拍按剧情单元分组（一次交锋、一次进场、一次收尾），每组 9–15 秒就是一段，**一段内要有情绪起伏（起势→反转）**——每 15 秒一个小反转，短剧爽点密度。
2. **段内切镜**，每镜 1–6 秒（硬门），围着 3 秒打。一段通常 2–4 镜。
3. **每镜一图一提示词**：`frame` 分镜图提示词 + `seedancePrompt`（模型手写，validate 逐字对账）。生成时全套参考图喂给 Seedance。

## 定时长四步法

1. **台词定下限**：这镜认领的台词，字数 ÷ 5.5 = 至少要的秒数。情绪系数联动：紧张冲突 ×1.1、温情对话 ×0.9。
2. **类型定基准**：反应镜 / 插入特写 1–2s（无台词）· **情节镜（推动剧情的对话/动作）最低 2s** · 纯动作镜 2.5s · 基础镜头 3s · 信息量大（长台词/多动作/情绪重）4–6s。**"1 秒"只留给真反应镜，情节镜给足 2s 起**。
3. **长台词优先拆镜**：一段话超 5s 就先拆成两句两镜；拆不动再给到 6s（上限）。
4. **节奏相间**：长短深浅不匀——重台词后接 1s 反应（5s 接 1s 是教科书节奏）。

## 硬规则

1. **认领是地基。** 每个镜声明 `beats:[起,止]`，全场连续区间、不重不漏。切完在心里过一遍：每场第 1 拍到最后一拍都有主吗？
2. **秒数是下单不是估算。** 镜秒数 = Seedance 生成时长，写进 `seedancePrompt` 镜号行（`c01,4s`）——改秒数必须同步改 prompt，validate 逐字对账。
3. **台词装得下。** 认领节拍的台词秒数（÷5.5）≤ 镜秒数。4.4 秒的台词就给 5 秒的镜。
4. **结构化元数据四件套。** 每镜写空间/姿态/位置/情绪；姿态和位置**全画内角色**（分号分隔）、情绪**只写本镜主角**（带程度值）；位置含"面朝@谁"视线。
5. **@绑定 = 设定图。** 空间/姿态/位置/情绪里的 `@老张` `@蒲扇` 都是**上传的设定图**，必须 ∈ 资产库（角色/道具名字），质量门查。
6. **画面无文字。** 每镜 prompt 带「不出现任何文字字幕」；台词按剧本原语言，不翻译。
7. **禁慢速词。** 不用「缓缓/静静」，情绪译成身体动作（撇嘴/挑眉/咬牙）——短剧要快、冲、有张力。

## 导演运镜手感（不设门，但决定像不像专业分镜）

> **导演判断的三份参考（切镜前必读）**：`references/directing-read.md` 判断这段戏要干什么（转折/视角/权力/潜台词）→ `references/directing-engine.md` 决定每个镜怎么为意图服务（场景类型/景别/表演行为化/连贯性）→ `references/cinematography-shot-language.md` 给出镜头手段怎么说（镜头契约/景别用法/运镜语法）。下面这条是短剧节奏的手感，导演层是更深的判断依据。

- **3 秒一切是短剧的呼吸。** 竖屏观众的注意力就这个粒度——切快了信息断，切慢了人走。节奏带上应该深浅相间、长短相间。
- **黄金 3 秒。** 开篇前 3 秒必须有强冲突钩子，否则完播率极低、没推荐。
- **对话切正反打。** 问话给问话人的近景，答话切答话人的近景，来回跳；谁的台词信息量大，谁的脸给得近。
- **进场三件套，第一镜给运动主体。** 每集第一镜必须有主体运动——静物特写开场是死画面。新空间随后再定场：运动主体 → 大远景定场 → 关键局部特写。观众三秒内知道谁在动、在哪、看什么。
- **关键动作独立成镜。**「她一把按住箱盖」这种拍值得单独一格 1–2 秒的特写插入（insert）。
- **反应镜头是免费的戏。** 一句重台词之后，切听者的脸 1–2 秒，不用写词。
- **动接动。** 上一切结尾的动势（手伸向箱子）接下一切开头的动势（手被按住），切点选在动作中间。
- **段的最后一切留钩。** 每段结尾的镜要么是悬念的具象，要么是下一段的引子——段与段之间也是剪辑点。
- **运镜克制。** 固定镜头是默认；推给情绪、拉给收场、跟给移动。一段里超过两种运镜就该问自己是不是在炫技。**克制 ≠ 全固定**——该拍的戏类型有权打破默认（灾难戏升降、揭示戏推近、权力戏低机位，见 `references/cinematography-shot-language.md`），只是每种运动都要有"为什么要在这"的理由，不为动而动。

## 参考图纪律（分镜图质量的一半在这）

分镜图生成 = 提示词 + 参考图。切镜时就想好每格要挂哪些参考：

- 场景设定图（该段场景 + 光照状态）——必挂，同时记入 `sceneImage`
- 画内每个角色的设定图——有几个挂几个（`@角色`）
- 画内叙事道具的设定图——有就挂（`@道具`）

提示词与参考图冲突时，模型听参考图的——所以提示词专心写构图、**此刻的位置状态**（已上船 / 在舱内 / 在桥头）和姿态，长相材质交给参考图。画面里出现的大资产（船、车、宅门）也要挂它自己的设定图，不挂就每帧长得不一样。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 舞台剧病 | 一段一切杵到底 | 对话切正反打，动作给插入特写 |
| 均匀病 | 每镜都是 3 秒中景 | 深浅相间、长短相间才是节奏 |
| 秒数漂移 | 改了镜秒数忘改提示词 | validate 会拦：镜号行逐字对账 |
| 台词爆仓 | 4.4 秒的台词塞 3 秒的镜 | 加秒或拆镜 |
| 元数据缺失 | 只写视觉描述，不写空间/姿态/位置/情绪 | 四件套是骨架，缺一不得 |
| @绑定乱写 | `@张三` 资产库里没有 | validate 拦：@绑定必须 ∈ 资产库 |
| 慢速词病 | 「缓缓转头」「静静看着」 | 换成具体动作：转头→挑眉/注视→目光下移 |
| 特写失忆 | 大特写的道具和设定图长得不一样 | 挂道具设定图当参考，提示词提锚点特征 |
| 换景不换段 | 一段里从栈桥切进船舱 | 换景必开新段——段内同场同景 |
| 改镜不读邻镜 | 第 1 镜改成岸路奔跑，第 2 镜还写着栈桥才露出来 | 改一镜连读前后镜——位置是连续状态 |
