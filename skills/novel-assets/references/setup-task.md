# 设定图提示词规范（出图包内 01_设定图提示词.txt）

由 `novel-assets.mjs run` 自动生成，打进 `<剧名>-出图包.zip`，GPT 读它生成设定图。这份是给 GPT 的指令，不是给人读的文档。

## 结构

```
你是一名美术总监，为短剧《X》一次性生成全部 N 张设定图。
【统一要求】  ← 画风锚点 + 依次生成 + 打包要求
【重要：记住这些设定图，后面还有用】 ← 分镜图要引用，必须强调记住
【每张图的提示词】
  【图1 · 林风】
  命名：林风-sheet.png
  提示词：<image.sheet 全文>
  【图2 · 童童】
  ...
```

## 关键规则

1. **提示词原样用 `image.sheet`**，一字不改。这些提示词已经是完整的英文设定图规格（四视图 + 细节 + 光照分区 + 16:9 版面）
2. **比例不写死 9:16**——设定图是资产图，`image.sheet` 内部已写 16:9 canvas，外部不要再加比例指令跟它打架。9:16 约束只给分镜图任务
3. **全传**：含第一集用不上的（萱华/白色纸人/婴儿房）也传，不筛选
4. **命名**：`<slug(名)>-sheet.png`，slug 转安全文件名（中文保留，非法字符转 -）
5. **「记住」段是灵魂**：设定图生成后分镜图要引用，必须明确告诉 GPT 记住每张形象——这是整个"GPT 自足"流程的依赖

## 比例冲突的坑

`image.sheet` 内部写 `ONE 16:9 landscape canvas`——这是**设定图的正确比例**（三视图+细节要横版才装得下）。如果任务文本开头再写"统一 9:16"，GPT 会收到两个冲突指令，可能把四视图挤成竖版。**所以设定图任务不写全局比例，分镜图任务才写。**

## 画风锚点

取 `--style` 参数（默认回退 `storyboard.style`，如"暗黑写实电影感"），放【统一要求】第 1 条。所有图都引用它，防画风漂移。

**源头带风格**：前置询问锁定的画风配方（见规则 feedback_pipeline_preflight_params）由 characters 写 sheet 时已带进 `image.sheet`——本任务**原样输出 sheet**（不重复写配方），只写风格名锚点。飞书特化风格的样张图（画风锚）由说明.txt 统一说明，不在本任务内重复。负面词由说明.txt 的【统一画风】段写（GPT 网页版无负面词栏）。
